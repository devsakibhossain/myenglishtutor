## ✨ কী কী সুপারপাওয়ার রয়েছে?

### ১. 📸 ছবি ও স্ক্রিনশট রিডার (Image / Vision)
* বায়ারের মেসেজ বা জটিল ইমেইলের স্ক্রিনশট পাঠালে তার ভেতরের অর্থ বুঝিয়ে দেবে এবং কীভাবে প্রফেশনাল উত্তর দেবেন তা সাজিয়ে দেবে।
* বইয়ের পাতা বা ইংরেজি পরীক্ষার প্রশ্ন পাঠালে সঠিক উত্তর ও ব্যাখ্যা দেবে।

### ২. 🎬 ভিডিও লিসেনিং ও স্ল্যাং অ্যানালাইজার (Video Understanding)
* ইংরেজি মুভি ক্লিপ, রিল বা ইউটিউব শর্ট পাঠালে বট ভিডিও শুনে সংলাপ লিখে দেবে।
* নেটিভরা কীভাবে ফাস্ট ও জোড়া লাগিয়ে কথা বলেছে (Connected speech) তা বাংলায় বুঝিয়ে দেবে।

### ৩. 🎙️ ভয়েস কথোপকথন ও রিয়েল অডিও রিপ্লাই (Voice & Neural Audio)
* আপনি মুখে কথা বলে ভয়েস মেসেজ পাঠাতে পারেন। বট আপনার উচ্চারণ ঠিক করে দেবে।
* বট নিজেও আসল নেটিভ আমেরিকান মানুষের কণ্ঠে অডিও ভয়েস রিপ্লাই পাঠাবে, যাতে আপনি শুনে শুনে কথা বলা শিখতে পারেন।

### ৪. 💼 ফ্রিল্যান্সিং ও ক্লায়েন্ট কমিউনিকেশন (`/client <মেসেজ>`)
* বায়ারকে পাঠানোর মেসেজ বা ইমেইল পলিশ করে প্রফেশনাল আমেরিকান ও ব্রিটিশ স্টাইলে রূপান্তর করে দেবে।

### ৫. 🎧 কানে হেডফোন দিয়ে শোনার ট্রেনিং (`/listen`)
* ফাস্ট নেটিভ স্পিচের অডিও পাঠাবে এবং কুইজ নেবে।

## 📱 টেলিগ্রাম কমান্ড তালিকা

| কমান্ড | কাজ |
|---|---|
| `/listen` | ফাস্ট নেটিভ স্পোকেন অডিও টেস্ট |
| `/decode <বাক্য>` | যেকোনো নেটিভ স্ল্যাং/শর্টকাট বাংলায় ডিকোড করা |
| `/speak <শব্দ/বাক্য>` | যেকোনো বাক্যের আসল নেটিভ উচ্চারণ অডিও আকারে শোনা |
| `/client <মেসেজ>` | বায়ারের জন্য প্রফেশনাল মেসেজ ও ইমেইল তৈরি |
| `/accent` | অ্যাকসেন্ট নির্বাচন (American / British / Australian) |
| `/voice on\|off` | স্বয়ংক্রিয় ভয়েস রেসপন্স চালু বা বন্ধ রাখা |
| `/quiz` | ইন্টারঅ্যাক্টিভ নেটিভ স্পিচ কুইজ |
| `/lesson` | আজকের নেটিভ স্পিকিং টিপস |
| `/vocab` | গুরুত্বপূর্ণ নেটিভ স্ল্যাং বা ফ্রেজ |
| `/correct <বাক্য>` | বাক্যকে স্মার্ট নেটিভ বাক্যে রূপান্তর |
| `/stats` | আপনার স্ট্রিক ও অগ্রগতি |
| `/help` | হেল্প মেনু |
